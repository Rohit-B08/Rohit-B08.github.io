# Portfolio Website — Rohit-B08.github.io

## Stack
Static HTML/CSS, no build step or framework. Deployed via GitHub Pages
("Deploy from a branch" — pushes to `main` go live automatically).

## Design language
Departures-board aesthetic — dark background, monospace/flip-board style
lettering. Match this tone in any new sections or components.

## Structure
- index.html — homepage
- /css — stylesheets
- /assets — images, favicon, etc.

## Conventions
- Keep everything in plain HTML/CSS — no frameworks or build tools.
- Favicon and meta tags live in the <head> of every page — keep them
  in sync if adding new pages.
